# Bitácora de uso de IA

Herramienta utilizada: **Claude**.

| Herramienta y objetivo | Instrucción relevante (resumida) | Qué acepté, cambié o descarté | Cómo lo comprobé |
|---|---|---|---|
| Claude: organizar la prueba | Analizar el enunciado de la prueba, desglosar sus requisitos y definir un plan de trabajo paso a paso | Usé la estructura propuesta y pedí seguir el orden del documento | Comparando con el enunciado |
| Claude: generar la API | Preparar el repositorio y el entorno, indicar la base de datos y explicar el alcance de la API y cómo ejecutarla | Usé el código generado y lo reescribí para entender qué hace cada parte | Ejecutándolo y enviando peticiones POST y GET en Postman |

## Reflexión

1. La IA me hizo avanzar más rápido al organizar la prueba y definir su estructura.
2. También aceleró la generación del código base, las pruebas y la documentación.
3. La cuestioné cuando el avance no seguía el orden que yo quería.
4. Ajusté datos de ejemplo para acercarlos a un caso más realista.
5. Reescribir el código y probarlo me ayudó a entender su ejecución, no solo a copiarlo.
